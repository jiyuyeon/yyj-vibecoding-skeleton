# 바이브코딩 뼈대

AI(Claude 등)와 무엇을 만들든 처음부터 좋은 품질이 나오게 하는 규칙 모음이에요.

| 파일 | 무엇인가 |
|---|---|
| 뼈대-프롬프트.md | 일하는 방식, 기획, 디자인, 글쓰기, 화면 규칙, 화면 점검 절차. 새 프로젝트의 CLAUDE.md로 씀 |
| UXUI-근거집/ | 기능과 정보 종류마다 정론이 된 화면 부품 (닐슨 노먼 그룹, Apple HIG, 구글 머티리얼, GOV.UK, 베이마드, WCAG, 토스 TDS 등). 줄마다 출처 주소와 확인 날짜 |

## 쓰는 법

1. 뼈대-프롬프트.md에서 `---` 아래 내용을 새 프로젝트 폴더의 `CLAUDE.md`로 저장해요
2. UXUI-근거집 폴더를 프로젝트 폴더에 같이 넣어요
3. AI는 화면 부품을 고를 때 `UXUI-근거집/0-찾아보기.md`에서 상황을 찾아 그 줄만 읽어요. 전체(약 13만 자)를 매번 읽지 않아 토큰이 적게 들어요
4. 근거집에 없는 상황이면 AI가 같은 출처에서 찾아 한 줄 더해요. 더한 줄은 이 저장소에도 올려 주세요

## 새 판 받기

- 저장소를 내려받았다면 `git pull`
- 아니면 GitHub 화면의 Code, Download ZIP

바뀐 내용은 커밋 기록에 남아요. 파일 이름에는 판 번호를 붙이지 않아요.
