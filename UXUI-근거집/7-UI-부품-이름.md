# UI 부품 이름 (한국어, 영어, Apple, 머티리얼, 토스 이름과 헷갈리는 이웃)

- 조사일 2026-11-24, 모든 출처는 이날 직접 열어 확인
- 부품 이름은 공식 디자인 시스템에서 가져옴: 애플 HIG(Human Interface Guidelines), 머티리얼 3(구글 디자인 시스템), 토스 TDS(Toss Design System, 모바일), W3C ARIA APG(ARIA Authoring Practices Guide, 웹 접근성 부품 패턴)
- 한국어 이름 칸만 공식 출처가 없음. 국내 디자이너와 개발자가 흔히 부르는 말을 적었고, 판단이 들어간 칸임
- 애플 HIG는 같은 본문의 데이터 주소(developer.apple.com/tutorials/data/design/human-interface-guidelines/페이지이름.json)로 열어 읽음. 표에는 사람이 보는 주소를 적음
- 머티리얼 3 공식 사이트(m3.material.io)는 글이 스크립트로 그려져 읽히지 않음. 안드로이드 개발자 문서(developer.android.com)와 머티리얼 컴포넌트 안드로이드 저장소 문서(github.com/material-components)로 대신 확인
- 플랫폼 이름 칸에서 "없음"은 그 시스템의 부품 목록에 해당 부품이 따로 없다는 뜻
- 애플 HIG, 토스 TDS, 안드로이드 문서는 페이지에 게시일 표시가 없어 날짜를 적지 않음. NN/g(Nielsen Norman Group) 글만 게시일을 붙임

## 자주 헷갈리는 짝 요약

| 짝 | 나누는 기준 | 근거 |

| 모달, 다이얼로그, 얼럿 | 모달은 뒤 화면을 막는 방식 이름. 다이얼로그는 창 부품. 얼럿은 짧고 중요한 메시지에 대답을 받는 다이얼로그 | APG Dialog, NN/g, 애플 Alerts |

| 셀렉트, 메뉴, 콤보박스 | 셀렉트는 값 하나를 고름. 메뉴는 명령을 실행. 콤보박스는 글자를 쳐서 후보를 좁힘 | 애플 Pull-down buttons, APG Combobox, NN/g |
| 스위치, 체크박스 | 누르면 바로 적용되면 스위치, 저장을 눌러야 적용되면 체크박스 | NN/g, 애플 Toggles |
| 탭, 세그먼트 컨트롤, 탭 바 | 탭 바는 앱의 큰 구역 이동. 탭은 한 화면 안 내용 묶음 전환. 세그먼트 컨트롤은 밀접한 보기나 선택지 하나 고르기 | 애플 Segmented controls, 애플 Tab bars |
| 바텀시트, 사이드 시트, 드로어, 액션 시트 | 바텀시트는 아래에 붙은 판. 사이드 시트는 옆에 붙은 보조 내용 판. 드로어는 옆에서 나오는 이동 메뉴. 액션 시트는 동작에 대한 선택지 목록 | 머티리얼 문서, 애플 Action sheets |
| 칩, 배지, 태그 | 칩은 누르는 부품(필터, 입력, 제안). 배지는 누르지 않는 숫자나 상태 표시. 태그는 분류 이름표로 흔히 혼용 | 머티리얼 Chip, 머티리얼 Badge, component.gallery |
| 스테퍼(수량), 스테퍼(단계) | 애플 Stepper는 더하기 빼기 숫자 조절. 토스 Stepper는 여러 단계 표시. 기획서에는 "수량 조절"과 "단계 표시"로 나눠 쓰기 | 애플 Steppers, 토스 Stepper, 토스 NumericSpinner |
| 내비게이션 바 | 애플에서는 위쪽 제목 막대, 머티리얼에서는 아래쪽 탭 막대. 이름이 정반대로 겹침 | 애플 Toolbars, 안드로이드 Navigation bar |

## 확인 못 한 것

- 한국어 이름 칸은 공식 출처가 없음. 국내 현업에서 흔히 부르는 말을 적은 판단이라 회사마다 다를 수 있음
- 머티리얼 3 공식 사이트(m3.material.io)는 글이 읽히지 않아 열지 못함. 이름과 정의는 안드로이드 개발자 문서와 머티리얼 컴포넌트 안드로이드 저장소 문서로 확인함. 두 문서는 사이트와 시점이 다를 수 있음
- 머티리얼 Banner 정의는 확인 못 함. 안드로이드 Banner 문서는 "아직 미완성"이고, 머티리얼 2 배너 페이지(m2.material.io)도 글이 읽히지 않음
- 머티리얼 Tooltip 안드로이드 문서도 미완성. plain과 rich 구분은 안드로이드 Compose 문서로 확인함
- 머티리얼에 콤보박스(입력 가능한 드롭다운)를 부르는 별도 이름이 있는지 확인 못 함
- 머티리얼의 마진, 세이프 에어리어(안드로이드 WindowInsets) 정의 문서는 열지 않음
- 토스 TDS는 모바일 웹 문서(tds-mobile)의 부품 목록만 확인함. Border, TableRow, GridList는 이름만 보고 정의는 열지 않음. 토스 Loader가 도는 모양인지 점 모양인지 문서에 없음. React Native 문서(tds-react-native)와 목록이 다를 수 있음
- 토스 부품 목록에 Card, Radio, Chip, Avatar, Date picker, Popover가 없음. 다른 이름으로 들어 있을 가능성은 확인 못 함
- 애플 "없음"은 HIG 부품 목록(Components 아래 8개 묶음)에 해당 페이지가 없다는 뜻. SwiftUI 같은 개발 API에만 있는 부품(예: 빈 화면용 ContentUnavailableView)은 확인하지 않음
- 애플 HIG Action sheets 페이지에는 iPad에서 팝오버로 뜨는지에 대한 설명이 없음
- 웹 쪽 이름 중 env(safe-area-inset-*), position: sticky, details 요소, kbd 요소는 MDN을 열어 확인하지 않음
- APG Tooltip 패턴은 문서 스스로 "작업 중, 합의 전"이라고 밝힘
- 머티리얼 Navigation drawer, Segmented button의 지원 종료 예정은 안드로이드 저장소 문서 기준. 실제 종료 시점은 확인 못 함
