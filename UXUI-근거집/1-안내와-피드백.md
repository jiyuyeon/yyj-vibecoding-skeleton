## 확인 못 한 것

- Material Design 3 공식 페이지(m3.material.io의 스낵바, 진행 표시 지침)는 화면이 스크립트로 그려져 본문을 읽지 못함. 대신 같은 팀의 Material Components Android 스낵바 문서(한 번에 하나, 실행취소나 다시 시도 단추 하나)를 씀. M3의 표시 시간 권장값은 확인 못 함
- 토스 기술 블로그에서 로딩, 스켈레톤, 축하 화면을 다룬 글은 검색으로 찾지 못함. 토스 쪽 근거는 TDS 컴포넌트 문서(Skeleton, Toast)뿐. TDS Skeleton 문서에는 움직임(밝아졌다 어두워짐) 언급이 없음
- 스켈레톤 애니메이션의 속도 값("천천히")은 어느 출처에도 수치가 없음
- NN/g의 토스트 전용 글, 축하(색종이 등) 전용 글은 찾지 못함
- 버전 기록(이전 버전으로 되돌리기)을 오류 회복 수단으로 다룬 플랫폼 지침은 찾지 못함. NN/g 사용자 통제 글도 다루지 않음
- Buell, Norton 논문은 서지 페이지의 초록만 읽음(출판사 페이지와 하버드 페이지는 접근 거부). 본문 수치는 확인 못 함
- Baymard의 오류 문구 위치 전용 지침은 찾지 못함. 위치 근거는 NN/g와 GOV.UK
