## 확인 못 한 것

- 머티리얼 디자인 3 공식 사이트(m3.material.io)는 화면을 스크립트로 그려서 본문을 열지 못했다. 대신 구글의 머티리얼 안드로이드 깃허브 문서를 읽었다. 이 문서에 따르면 세그먼트 버튼은 M3 Expressive 개편에서 폐지 예정이고 연결된 버튼 그룹(connected button group)으로 바뀐다
- 애플 HIG는 웹 화면 대신 같은 내용의 데이터 주소(developer.apple.com/tutorials/data/design/human-interface-guidelines/...json)로 읽었다. 날짜는 각 쪽 변경 기록의 가장 최근 항목이다
- 토스 TDS 문서에는 날짜가 없고, 쓰는 법(코드 속성) 위주라 "언제 쓰라"는 지침은 적다. 토스 TDS 공개 문서는 앱인토스용이다
- 마우스 올릴 때만 나오는 바꾸기, 지우기 버튼이 터치에서 문제라는 것을 직접 다룬 NN/g, 애플, GOV.UK 글은 찾지 못했다. NN/g 툴팁 글(hover는 터치에서 보통 안 됨)에서 미루어 본 판단이다. WCAG 1.4.13도 터치 기기는 언급하지 않는다
- 올린 파일 미리보기와 바꾸기, 지우기 버튼에 대한 GOV.UK 지침은 없었다. DWP의 "올린 파일 다루기" 쪽은 열지 않았다
- 아래 고정 버튼이 전환율이나 완료율을 높인다는 독립 연구(NN/g, 베이마드)는 찾지 못했다. 찾은 것은 업체 A/B 시험 사례뿐이라 근거로 쓰지 않았다
- 베이마드 상세 지침(가이드라인 번호 쪽)은 유료라 공개 글만 읽었다
- 안드로이드 키보드 문서의 수정일은 확인하지 못했다
- NN/g의 세그먼트 컨트롤 전용 글은 찾지 못했다
